# Roadmap Decisions

## Current assumptions

- Keep the dark/glass visual direction and refine it into a clearer casino table.
- Preserve the current shared local game while stabilizing it.
- Treat modern mobile browsers down to approximately `320px` as supported.
- Defer betting, accounts, persistence, matchmaking, and real online rooms.

## Decisions to revisit

- Whether local multiplayer identity and room behavior should move earlier than planned.
- Whether sound belongs in the table redesign or a later enhancement.
- Which browser/device matrix should be used for final manual verification.
