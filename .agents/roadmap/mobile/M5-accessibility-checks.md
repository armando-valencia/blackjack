# M5 — Responsive Accessibility Checks

Branch: `test/mobile-accessibility-checks`

## Scope

- Verify keyboard navigation, visible focus, semantic buttons, labels, contrast, and reduced motion.
- Test representative phone and desktop viewport sizes.
- Maintain a repeatable manual verification checklist.

## Acceptance criteria

- Core gameplay works without a mouse.
- Status changes are understandable to assistive technology.
- Responsive checks can be repeated for future PRs.
