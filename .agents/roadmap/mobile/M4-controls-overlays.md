# M4 — Mobile Controls and Overlays

Branch: `feature/mobile-controls-overlays`

## Scope

- Make the action rail thumb-friendly and safe-area aware.
- Position connection and error feedback away from essential controls.
- Add touch-friendly focus and pressed states.
- Handle viewport changes without trapping users behind overlays.

## Acceptance criteria

- Hit and Stand are easy to use one-handed.
- Toasts do not obscure essential state.
- Controls remain available on short screens.

## Dependencies

- M1.
- M3.
