# M1 — Mobile Layout Foundation

Branch: `feature/mobile-layout-foundation`

## Scope

- Define supported viewport sizes and breakpoints.
- Remove fixed assumptions causing horizontal overflow.
- Handle narrow and short viewports.

## Acceptance criteria

- No horizontal page scrolling at supported widths.
- Dealer, player, message, and controls remain visible on a phone.
- Desktop layout remains intact.

## Dependencies

- T6.
