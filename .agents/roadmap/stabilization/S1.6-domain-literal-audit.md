# S1.6 — Domain Literal Audit

Branch: `refactor/stabilization-domain-literal-audit`

## Scope

- Audit server, client, and tests for repeated domain and protocol magic strings.
- Centralize game statuses, player statuses, results, command types, hidden-card markers, card tokens, and other repeated machine values in their owning modules.
- Preserve serialized WebSocket values and user-facing copy.
- Migrate tests and production code to the named values.
- Record intentional literals that should remain strings, such as display copy and external wire values.

## Acceptance criteria

- Repeated machine values have one authoritative definition per domain boundary.
- Tests do not duplicate machine-value literals unnecessarily.
- Protocol serialization remains backward-compatible.
- The audit covers both Python and TypeScript code.
- No broad abstraction is introduced for one-off values.
