# T1 — Table Design System

Branch: `feature/table-design-system`

## Scope

- Define reusable tokens for table colors, surfaces, text, spacing, borders, focus states, and result states.
- Define idle, active-turn, waiting, bust, win, loss, push, and dealer-turn states.
- Establish desktop and narrow-screen layout rules.

## Acceptance criteria

- Visual decisions use reusable styles or components.
- New table components avoid scattered one-off values.
- Focus and contrast states are defined.

## Dependencies

- S7.
